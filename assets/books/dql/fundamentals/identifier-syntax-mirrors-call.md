
# Identifiers Mirror Call Sites {.dqlh}

In many programming languages the identifier always matches a particular grammar wherein the identifier may stand for a scalar, a function, a data structure, etc.

Thus, for example, the identifier `execute` could be a variable that holds an entity from different abstraction levels.  This is especially prevelant in functional programming languages.

Delightql makes the identifier *structured*.  The main place in which this matters is in the parameter list of a higher-order rule.
