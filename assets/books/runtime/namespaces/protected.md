
# Special Protected Namespaces {.dqlh}

A programmer has wide latitude to create
their own tree of namespaces anywhere in the image
inclusive of entities within those namespaces.


Delightql sets aside the following namespaces
as protected classes:

  - `std`-prefixed namespaces may not receive new entities nor add or drop namespaces
  - `sys`-prefixed namespaces may not receive new entities nor add or drop namespaces
