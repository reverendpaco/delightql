
# Information Schema Namespaces {.dqlh}


The following namespaces contain entities that allow
introspection of what entities are knowable at runtime.
These namespaces contain multiple table or view entities
that are created, modified or deleted whenever a programmer runs `consult!`, `mount!`,
etc.

 - `sys::ns`
 - `sys::cartridges`
 - `sys::entities`
 - `sys::entities::ho`
 - `sys::entities::interior`
